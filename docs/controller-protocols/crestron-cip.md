# Crestron CIP

## 范围

当前适配器通过 TCP 使用 CIP Raw，与现有 CIP 模拟器互通。控制点目前只支持数字 Join：每个控制点配置一个发送 Join、一个状态接收 Join 和一个使能接收 Join。

控制器地址和端口由中控配置提供；默认 Raw 端口为 `41794`。连接使用配置的 IPID。当前仅实现 Raw 报文，不实现其他帧封装或摄像头、触摸屏管理能力。

协议实现位于 [CrestronCipAdapter.cs](../../backend/RoomControl.Api/Integrations/CrestronCipAdapter.cs) 和 [CipProtocolCodec.cs](../../backend/RoomControl.Api/Integrations/CipProtocolCodec.cs)，TCP 交互测试位于 [CrestronCipAdapterTests.cs](../../backend/RoomControl.Api.Tests/CrestronCipAdapterTests.cs)。

## TCP 报文格式

每条 CIP 消息按以下结构传输：

| 字段 | 长度 | 说明 |
| --- | ---: | --- |
| Type | 1 字节 | 消息类型 |
| Reserved | 1 字节 | 当前实现要求为 `0x00` |
| Payload Length | 1 字节 | 后续 Payload 的字节数 |
| Payload | 0–255 字节 | 消息数据 |

数值型 Join 数据中的 16 位无符号整数使用大端序。TCP 是字节流，接收端须先读取 3 字节头，再按 Payload Length 读取完整负载；一次 TCP 读取不一定对应一条完整 CIP 消息。

## 注册与连接

1. 客户端连接配置的 TCP 地址和端口。
2. 等待服务器的设备查询消息（Type `0x0F`）。
3. 客户端发送 Sign-On 消息（Type `0x0A`，Payload 长 11 字节）；IPID 放在 Payload 第 2 字节。
4. 等待注册结果：
   - 接受：Type `0x02`，Payload 为 `00 00 00 1F`。
   - 拒绝：Type `0x02`，Payload 为 `FF FF 02`。
5. 注册成功后发送 Join 状态请求。

注册等待有 20 秒超时。注册被拒绝或连接异常时，适配器报告连接失败，由连接管理服务重试。

## Join 状态与指令

Join 编号对外从 1 开始；报文中的编号从 0 开始。数字 Join 最大编号为 32768。发送、状态接收和使能接收编号分别独立配置。

| 类型 | Join Type | 编码与当前实现 |
| --- | ---: | --- |
| 状态请求 | `0x03` | Type `0x05` 的 Join Event，数据为 `00`；注册后及发送控制指令后请求一次状态。 |
| 状态回放结束 | `0x03` | Type `0x05` 的 Join Event，数据为 `16`（结束）/`1C`（就绪）；一次回放的结束标记。 |
| 数字状态 | `0x00` | 控制器上报的数字 Join；编号最高位表示状态，`0` 为开启，`1` 为关闭。状态接收 Join 用于显示控制点状态，使能接收 Join 用于控制按钮是否可操作。 |
| 数字按钮/脉冲 | `0x27` | 控制台点击或自动任务执行时，对发送 Join 依次发送激活和非激活状态，形成一次脉冲。 |

使能 Join 编号默认为 `0`，表示未配置并默认允许控制；配置有效 Join 编号后按高电平启用处理。每次建立连接后使能状态先重置为低电平，收到本次连接的高电平上报前，控制台按钮禁用，后端也拒绝手动脉冲请求。使能只限制人工操作：自动任务属于自动执行，不受使能 Join 约束，只要求中控在线。控制点状态只有高/低两种：状态接收 Join 未收到上报、或服务启动后尚未收到设备回报时，按默认值 `0`（关闭、低电平）处理，不会出现“未知”状态。平台以状态接收 Join 上报值作为最终设备状态，不将“指令已写入 TCP”视为设备状态已改变。

中控在全量回放时只上报当前为高电平的 Join，为低的 Join 不上报。平台以回放结束标记（`16`）为界，把本次回放窗口内未上报的状态接收 Join 视为低电平（`0`）并推送给前端，避免界面停留在过期的高电平；未参与本次回放的使能 Join 不受影响。

旧版本的数字控制点沿用原 Join 作为发送和状态接收编号；使能编号为 `0` 或未配置时默认允许操作。既有模拟/串口映射保留在数据库但不再显示或支持操作，其关联自动任务会在启动时删除。

## 心跳与断连

- 连接期间收到 Type `0x0D` 时，适配器发送 `0E 00 02 00 00` 响应；心跳只用于维持协议链路，不写入数据库，也不在界面显示。
- TCP 读取失败、连接关闭或协议报文无效时，连接标记为离线并由后台连接管理器重试。
- 状态快照保存在后端数据库；断连后保留最后一次状态与上报时间，服务重启时将全部快照重置为低电平，等待设备回报后再刷新。

## 验证边界

自动化测试使用本地 TCP 模拟端覆盖 Raw 注册、Join 指令、状态请求和状态回报。该测试验证当前实现的报文互通行为，不等同于真实 Crestron 硬件认证。接入具体型号前应以设备配置和现场联调确认 IPID、端口及 Join 行为。
