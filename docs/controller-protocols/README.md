# 中控协议说明

本目录集中记录平台支持的中控协议，新增中控品牌或协议时，为其新增一份 Markdown 文档，并在本索引中登记。

## 文档约定

- 文件名使用小写英文和连字符，优先使用品牌与协议名，例如 `crestron-cip.md`。
- 说明连接方式、端口、报文格式、登录/注册流程、状态上报、指令编码、超时与断连处理。
- 标明实现范围、已验证的模拟器/设备和未覆盖的协议能力；不要将模拟器互通测试描述为真实硬件认证。
- 协议行为以代码和对应测试为准，协议文档变更时同步更新实现及测试。
